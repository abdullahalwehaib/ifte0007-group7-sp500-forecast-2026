# Public and restricted evidence

The public package contains calculation code, saved coefficients and aggregate
results approved for this release, plus synthetic inputs and synthetic outputs.
It deliberately excludes genuine historical price sequences, individual genuine
forecast/error rows, original screenshots, personal identifiers and full private
conversation transcripts.

Historical modelling data were attributed to FRED SP500, with S&P Dow Jones
Indices LLC as the original provider. Only the final origin used an expressly
authorised Yahoo Finance ^GSPC daily Close fallback. These source descriptions
identify the research inputs; they are not a licence to republish observations.
Original download times and historical vintages were not established.

Authorised genuine data and detailed reproduction receipts are kept separately
as restricted evidence. Any institutional delivery of restricted files must use
the permitted channel and access conditions. Public repository access provides
neither vendor data rights nor permission to redistribute private inputs.

`data/synthetic_prices.csv` is generated by the fixed-seed program in
`src/sp500_forecast/synthetic.py`. No real observation, fitted residual or real
coefficient is used to produce that artificial sequence. Every row and generated
demonstration output is labelled as synthetic. Its scores cannot verify the
genuine historical performance figures.

Private CLI inputs and outputs must remain outside the public repository. The
code refuses a private run whose input or output is inside the repository. Do
not add private results to a commit or remove their private-data labels.
